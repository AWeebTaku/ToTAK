# Legacy (original Python game)

The original ASCII version of Tombs of the Ancient Kings, built with Python and
[tcod](https://github.com/libtcod/python-tcod) following the libtcod roguelike tutorial. It is kept for reference only and
is **not** part of the current game or its releases.

```bash
cd legacy
pip install -r requirements.txt
python main.py
```
